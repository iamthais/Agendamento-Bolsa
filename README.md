# Sistema de Pré-Cadastro em Hospitais  

## 🏥 Descrição  
Este projeto é um sistema de pré-cadastro desenvolvido para facilitar o registro de pacientes em hospitais. 
Ele permite que os pacientes realizem seu cadastro antecipado, agilizando o processo de atendimento e reduzindo filas na recepção.  

## 🚀 Funcionalidades até o momento
- **Cadastro de pacientes**: Permite que pacientes insiram informações pessoais e médicas antes de chegar ao hospital ou enquanto aguardam atendimento.
- **Gerenciamento de registros**: Interface administrativa para visualizar, editar ou excluir cadastros de pacientes.   

## 📋 Tecnologias Utilizadas até o momento
 *PHP, JavaSript, HTML, CSS e BootsTrap*
